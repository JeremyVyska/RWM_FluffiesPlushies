# Fluffies Plushies (retired)

> There are rumors of a strange fluffy creature roaming this world.  This is a cuddly (less sentient) homemade version.

This mod has retired. The fluffy plushies (and their hand-drawn art) now live in the main mods:

- [Big Fluffies](https://github.com/JeremyVyska/RWM_BigFluffies): pink fluffy plushies
- [Albino Fluffies](https://github.com/JeremyVyska/RWM_AlbinoFluffies): white fluffy plushies

With [Plushies](https://steamcommunity.com/sharedfiles/filedetails/?id=2259582816) by Twokay also active, colonists cuddle fluffy plushies and sleep better next to them.

This mod is now empty, so existing subscribers don't get duplicate plushies. It's safe to unsubscribe.
